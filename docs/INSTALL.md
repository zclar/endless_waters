# Installation and gameplay notes

## Windows, Android, and iOS

Download [Endless_Waters.mcaddon](https://github.com/zclar/endless_waters/raw/refs/heads/main/dist/Endless_Waters.mcaddon). Open/share the file with Minecraft, wait for both successful import messages, and activate both packs on a new **normal/infinite** world.

Target: Bedrock **26.50+ / Wilderness Bound**, with stable `@minecraft/server` 2.10.0. Enable cheats. Leave experiments off. This pack is not a Java data pack, Java mod, Marketplace purchase, or a pre-generated map.

The ocean and island terrain is generated by native features as new chunks appear. Island buildings and scenery use the stable Script API and may take a little longer to appear. The first harbor takes longer because nearby chunks must be prepared too. A brief welcome message confirms that scripts are running.

## Starting your voyage

- Your starting harbor is around **X=112, Z=112**. The safe spawn is just south of its market.
- The supply chest is beside the southern path. Other houses and the dock have vanilla loot.
- Follow the dock to a normal rowing boat. The large sailing ship nearby is an explorable build, with a cabin, hold, loot, and a boarding ladder.
- Friendly harbors have villagers and farms. Pirate harbors and watchtowers have hostile pillagers. Estates contain vindicators and an evoker.
- Autumn islands use Wilderness Bound poplar and red shrubs. Abandoned camps are native structures and use the game's own current loot.
- Tuff entrance huts on some islands mark the added underground trial chambers. Their ladders lead down to a landing near the chamber; some digging may be needed to reach the nearest room.

## Scope notes

| Request | This version |
| --- | --- |
| Endless water and small islands | Native chunk generation, no finite prebuilt world boundary. Seabed is mostly level; caves and terrain below Y=24 remain native. |
| One or two biomes per island | One or two landscape themes. The actual surface biome is a custom ocean biome, so forest/desert/taiga themes do not reproduce all vanilla climate and spawning rules. |
| More villages and outposts | New original island villages with real villagers, beds, and workstations; original pillager towers. These do not increase the game's built-in village/outpost placement setting. |
| Woodland mansions | Smaller original illager estates that fit the islands, with vanilla mansion loot and illagers; not full vanilla mansion layouts. |
| Trial chambers | Additional actual native chambers, retaining their configured spawners and vaults. |
| Wilderness Bound | Native abandoned camps and their loot; autumn poplar scenery. No invented items. |
| Boats | Normal usable Minecraft boats, plus stationary sailing-ship builds. |

Surface replacement removes the original above-ground terrain and structures. Underground portions above Y=23 can also be cut away. The add-on does **not** preserve every naturally generated stronghold room, monument, village, or mansion. Vanilla explorer maps, `/locate`, and eyes of ender do not point to this add-on's scripted settlements; some vanilla destinations can have been removed by the ocean pass. End access through a particular native stronghold is therefore not guaranteed. Nether and End content is otherwise unchanged.

Island terrain uses a deterministic coordinate/noise formula rather than a modified Mojang continentalness generator. Island sites are arranged in 224-block regions with open-water gaps; this regularity can become apparent on a large map. The world seed controls settlement choices and theme combinations. This version does not promise a different island outline for every seed.

Landmarks are intended to be more frequent than rare vanilla surface discoveries: about 71% of present islands have a settlement/camp/estate, 42% have a ship, and 20% have an additional trial chamber. These are placement settings, not a measured comparison against every vanilla seed. The starting harbor is guaranteed.

The first generation of an island can briefly add scenery near you. Generation state persists across saves, including partially completed builds. Do not remove/reinstall the pack, edit its UUID, or update its generation code on a valued world without a copy. Once finished, an island is never automatically rebuilt.

## Servers and consoles

For a Bedrock dedicated server, install both pack folders, activate their UUIDs in the world's `world_behavior_packs.json` and `world_resource_packs.json`, and use a fresh normal world with `allow-cheats=true`. The repository's manifests contain the exact IDs and versions.

Direct `.mcaddon` import is intended for Windows/mobile. Console and Realm delivery has not been tested; a Windows/mobile-hosted world is generally the practical starting point for those platforms. Do not assume a GitHub download can be opened directly on a console.

## Troubleshooting

- **No welcome message:** confirm the behavior pack is active, the game is at least 26.50, and the Script API dependency loaded. Check Settings → Creator → Content Log for errors.
- **Ordinary mainland at spawn:** confirm this is a newly created normal world with the pack enabled before creation. Existing terrain is not converted.
- **Harbor still preparing:** allow more time for chunk generation. This is heavier than a decoration-only add-on, especially on lower-powered devices.
- **Administrator status:** `/scriptevent endless:status` reports the active island build and starting-harbor state.
- **Missing loot or partial buildings:** copy the Content Log error and the coordinates. Failed generation pauses rather than silently declaring success.

Disable other world-generation add-ons when testing. Installation and visual checks on a Minecraft client remain part of the prototype's playtest checklist.
